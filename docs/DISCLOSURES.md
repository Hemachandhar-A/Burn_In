# Disclosures

Written by the Lead during the G7 check (Session 7a) on a clean clone of `develop` at 4c96659. Every row was re-checked against
the code or the committed results on that clone; items from the working list that are no longer true were dropped, and
items found during the check were added (#20-#28). This is the list of limitations a judge could notice, each with
the honest one-line statement. Where a row is also a *defect* that will be fixed rather than disclosed, that is said in the
last column.
